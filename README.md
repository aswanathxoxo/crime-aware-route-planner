# crime-aware-route-planner
ML-powered safe routing system for London - classifies crime-risk zones from Metropolitan Police data using Logistic Regression &amp; Random Forest, then navigates safer paths with Dijkstra and A* hybrid algorithms.

Built an end-to-end AI system using Metropolitan Police crime data - engineered spatial grid features, trained Logistic Regression and Random Forest classifiers (with ROC-AUC evaluation) for high-risk zone prediction, and implemented Dijkstra and A* hybrid algorithms to generate routes that balance distance efficiency with crime-risk avoidance. Stack: Python, Scikit-learn, OSMnx, Pandas, Matplotlib.
